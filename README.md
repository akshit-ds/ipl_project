# 🏏 IPL Data Analysis

## 📌 Project Overview
This project analyzes the IPL dataset using Python to answer various questions related to team performance, match results, and player statistics. The analysis is performed using Pandas and visualized with Matplotlib and Seaborn.

## 🎯 Features
- Load and analyze IPL dataset
- Answer case study questions
- Find top winning teams
- Compare wins by runs and wickets
- Identify top scorers
- Create data visualizations

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🚀 How to Run
1. Clone this repository.
2. Open the notebook in Jupyter Notebook.
3. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
4. Run the notebook cells.
